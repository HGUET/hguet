# HGUET

> **Community Edition direction (2026-11-27):** The organization profile text below is a proposed copy for manual publication; this file does not itself change GitHub organization settings. See the [release roadmap](../docs/release/community-0.1.0/ROADMAP.md).

**The open-source security toolkit for Solana transactions and autonomous agents.**

*Security should happen before the signature.*

[hguet.fr](https://hguet.fr) · [Public repository](https://github.com/HGUET/hguet)

HGUET is a local-first, non-custodial Rust toolkit for independent transaction analysis, trusted intent checks, transparent policies and reproducible adversarial testing. Community Edition is the primary free MIT-licensed product. No account or mandatory Cloud.

**Pre-alpha:** current analysis is partial and BLOCK-only; no automatic signing, safety guarantee or public paid Cloud. See the [implementation](https://github.com/HGUET/hguet/blob/main/docs/implementation/README.md) and [roadmap](https://github.com/HGUET/hguet/blob/main/docs/release/community-0.1.0/ROADMAP.md).

Optional private Cloud research remains separate. Contributions and independent test cases are welcome.

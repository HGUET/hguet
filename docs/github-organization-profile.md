# HGUET

> Proposed organization profile copy; this file does not itself change GitHub organization settings.

**Open-source security and transaction intelligence for Solana.**

*Understand before signing. Investigate after execution.*

[hguet.fr](https://hguet.fr) · [Public repository](https://github.com/HGUET/hguet)

HGUET is a local-first, non-custodial Rust toolkit for developers, wallet teams, security researchers and autonomous-agent integrators. Analyze original-wire asset movement, authority declarations and independent policy; compare transaction messages, inspect advisory RPC evidence and investigate historical transactions. Export machine-readable JSON or standalone HTML.

Community Edition is the primary free MIT-licensed toolkit. No account, custody, mandatory Cloud or signing permission. Current developer preview is not a public release or independent security audit. See [documentation](https://github.com/HGUET/hguet/blob/main/docs/README.md), [Demo Lab](https://github.com/HGUET/hguet/blob/main/docs/DEMO_LAB.md), and [verification](https://github.com/HGUET/hguet/blob/main/docs/release/community-0.1.0/VERIFICATION.md).

Optional private Cloud research remains separate. Independent fixtures, reviewed ground truth and security contributions are welcome.

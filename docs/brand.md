**Status:** working visual direction · November 2026

- **Name:** HGUET
- **Category:** Solana AI Agent Payment Security
- **Primary line:** Secure the intent. Verify the transaction.
- **Short supporting line:** Security before the signature.
- **Website:** https://hguet.fr
- **GitHub:** https://github.com/HGUET

### Public organization description (copy exactly)

`Open-source security for AI-agent payments on Solana. Verify intent, simulate transactions, understand risk — before signing.`

### Suggested organization profile settings

- **Name:** HGUET
- **Description:** the text above
- **Website:** https://hguet.fr
- **Location:** France (only if intentionally public)
- **Email:** leave empty until an official project mailbox exists
- **Avatar:** use the approved HGUET guardian/falcon emblem, **without text**, on a transparent background.

These are design-direction values, not an extracted exact palette from the approved image.

### Voice & claims

- Confident, technical, restrained. No hype around 'unhackable', 'quantum-proof' or 'guaranteed safe'.
- Separate *available* from *planned* capabilities.
- Never imply official Solana Foundation endorsement or SIRN/STRIDE partnership without confirmation.
- Use wording: `security analysis / advisory verdict` until enforcement in a signing workflow is demonstrated.
- No fake download counts, adoption numbers or audit badges.

## Organization README

The ready-to-publish organization Overview copy is in [github-organization-profile.md](github-organization-profile.md).

GitHub requires a third **public** repository named `.github`, with `profile/README.md` inside it, for an organization Overview README. `HGUET/hguet` README does **not** automatically become the organization Overview.

Because the agreed project structure has **two repositories**, this third metadata-only repository is not being created without a separate decision.

## Manual organization settings

Open https://github.com/organizations/HGUET/settings/profile to set the description, website and avatar; then pin `HGUET/hguet` as the featured public repository. The `HGUET/server` codebase must remain private.
